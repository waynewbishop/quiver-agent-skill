# Privacy Policy

The Quiver agent skill collects no data.

The skill is a set of Markdown instructions and reference files. It contains no scripts, hooks, MCP servers, or network code. It does not collect, store, or transmit personal information, usage data, or any content from your projects, and it has no analytics or telemetry.

When the skill is active, your coding agent reads its files and may read your project's `Package.swift` or `Package.resolved` to find the Quiver version. That reading happens inside your agent session. Anything the agent sends to its model provider is covered by that provider's privacy policy, not this one.

Questions about this policy can be raised as an issue at [github.com/waynewbishop/quiver-agent-skill/issues](https://github.com/waynewbishop/quiver-agent-skill/issues).
